1. EXECUTIVE OBJECTIVE
--------------------------------------------------------------------------------
Transform the web-based PowerStage CAD & Control Studio into a native, high-performance
Windows 64-bit desktop executable (`PowerStageStudio.exe`) that unlocks the full hardware
capabilities of a modern engineering workstation PC:
  - Multi-core CPU (16–64 threads via Rust `rayon` + AVX2/AVX-512 SIMD)
  - Dedicated GPU Compute (`wgpu` / DirectX 12 / Vulkan / CUDA compute shaders)
  - Native C/C++ SPICE & Finite-Element Magnetics solvers (`ngspice.dll`, `LTspice.exe`, `FEMM`)
  - Local high-speed SQLite/DuckDB offline database (500,000+ LCSC/Mouser/DigiKey parts + SPICE models)
  - Direct PC Hardware I/O (USB-TMC / VISA Oscilloscopes, Serial/CAN-FD DSP HIL live tuning)
  - Native EDA & CAD file system integration (KiCad 8 `.kicad_sch`/`.kicad_pcb`, `.STEP` 3D cores, CCS/STM32Cube projects)

2. WHY NATIVE PC (.EXE) VS. BROWSER SANDBOX?
--------------------------------------------------------------------------------
[Browser Limitation]                     -> [Native Windows .EXE Advantage]
- Single-threaded JS main thread         -> Rust `rayon` parallel thread-pool across all CPU cores
- ~500 design sweeps before UI freezes   -> 250,000+ Pareto & Monte Carlo sweeps in <180 ms (AVX2 SIMD)
- 1D analytical Dowell magnetics only    -> 2D/3D GPU Finite-Element (FEM) Poisson/Helmholtz flux solver
- Averaged state-space approximations    -> Cycle-accurate `ngspice.dll` FFI & headless `LTspice.exe -b`
- In-memory JSON array (~100 parts)      -> Local `rusqlite` FTS5 database with 500k+ parts & `.lib` curves
- Manual copy-paste of C filter code     -> Direct UART/CAN-FD/JTAG live telemetry & RAM coefficient hot-swap
- Simulated Bode plots only              -> Live SCPI/VISA overlay of physical Bode 100 / Keysight scope traces

3. ESSENTIAL TOOLS & MCP SERVERS FOR THE AI AGENT (ANTIGRAVITY)
--------------------------------------------------------------------------------
Before running the 8 build prompts, equip the Antigravity agent with these tools:

A. Core Compiler & Build Toolchain (Windows 11 x64):
   - Rust Toolchain: `rustup` (`stable-x86_64-pc-windows-msvc`), `cargo`, `clippy`, `rustfmt`
   - Visual Studio 2022 Build Tools: Desktop Development with C++ (MSVC v143, Windows 10/11 SDK)
   - Node.js 22 LTS + `pnpm` or `npm` (for Vite + React UI frontend)
   - Tauri v2 CLI: `cargo install tauri-cli@^2.0.0`

B. Agent MCP (Model Context Protocol) Servers & CLI Capabilities:
   - `filesystem-mcp`: Full read/write access to workspace, `%APPDATA%`, and KiCad/LTspice directories.
   - `terminal-mcp` / Bash/PowerShell runner: To run `cargo check --message-format=json`, `cargo test`, `pnpm build`.
   - `sqlite-mcp`: Allows the agent to inspect, seed, and verify the local `components.sqlite3` catalog.
   - `fetch / web-scraper-mcp`: Allows the agent to pull manufacturer `.lib`/`.subckt` SPICE models (Infineon, Wolfspeed, EPC, TDK, Ferroxcube).

C. External Engineering Sidecars (Bundled in `src-tauri/binaries/` or auto-detected):
   - `ngspice.dll` (Shared ngspice library v42+ loaded via Rust `libloading` FFI)
   - `LTspice.exe` (Auto-detected at `%LOCALAPPDATA%\Programs\ADI\LTspice\LTspice.exe`, invoked with `-b -Run`)
   - `femm.exe` (Finite Element Method Magnetics 4.2 invoked headlessly via Lua script IPC)
   - `kicad-cli.exe` (KiCad 8.0+ CLI for automated DRC, schematic ERC, and Gerber/3D STEP generation)
